Java宿舍管理系统

发表于 2019-10-11 分类于 java ， java项目 阅读次数： Valine：
本文字数： 字

系统概述

本项目是一个基于Java Swing + MySQL的宿舍管理系统，旨在为学校宿舍管理提供便捷的信息化解决方案。系统实现了学生入住管理、宿舍分配、报修管理、访客登记等核心功能，采用C/S架构，界面友好，操作简单。

开发环境：
JDK 1.8
MySQL 5.7
IDE：Eclipse
界面框架：Java Swing
数据库驱动：JDBC

功能模块

1. 学生管理

学生信息的增删改查，包括学号、姓名、性别、班级、联系方式、宿舍号等基本信息的管理。支持按学号、姓名等条件模糊查询。

2. 宿舍管理

宿舍信息的维护，包括宿舍楼号、房间号、床位数、已入住人数、宿舍类型等。支持宿舍分配、调换、退宿等操作，实时更新宿舍空余床位信息。

3. 报修管理

学生在线提交报修申请，填写报修类型（水电、门窗、空调等）、报修描述。管理员可查看报修列表，指派维修人员，更新维修状态（待处理、维修中、已完成）。

4. 访客登记

来访人员信息登记，包括访客姓名、联系方式、被访人、来访事由、来访时间、离开时间等，保障宿舍安全。

数据库设计

学生表（t_student）

CREATE TABLE t_student (
  id INT PRIMARY KEY AUTO_INCREMENT,
  student_no VARCHAR(20) NOT NULL UNIQUE,
  name VARCHAR(50) NOT NULL,
  gender VARCHAR(10),
  class_name VARCHAR(50),
  phone VARCHAR(20),
  dorm_id INT,
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (dorm_id) REFERENCES t_dorm(id)
);

宿舍表（t_dorm）

CREATE TABLE t_dorm (
  id INT PRIMARY KEY AUTO_INCREMENT,
  building VARCHAR(50) NOT NULL,
  room_no VARCHAR(20) NOT NULL,
  bed_count INT DEFAULT 4,
  used_bed INT DEFAULT 0,
  dorm_type VARCHAR(20),
  remark VARCHAR(200)
);

报修表（t_repair）

CREATE TABLE t_repair (
  id INT PRIMARY KEY AUTO_INCREMENT,
  student_id INT,
  repair_type VARCHAR(50),
  description TEXT,
  status VARCHAR(20) DEFAULT '待处理',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  update_time DATETIME,
  FOREIGN KEY (student_id) REFERENCES t_student(id)
);

public class DBUtil {
    private static final String URL = "jdbc:mysql://localhost:3306/dormitory?useSSL=false&characterEncoding=utf-8";
    private static final String USER = "root";
    private static final String PASSWORD = "root";

    static {
        try {
            Class.forName("com.mysql.jdbc.Driver");
        } catch (ClassNotFoundException e) {
            e.printStackTrace();
        }
    }

    public static Connection getConnection() throws SQLException {
        return DriverManager.getConnection(URL, USER, PASSWORD);
    }

    public static void close(Connection conn, PreparedStatement ps, ResultSet rs) {
        try {
            if (rs != null) rs.close();
            if (ps != null) ps.close();
            if (conn != null) conn.close();
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}

宿舍分配逻辑

public class DormService {

    // 分配宿舍：查询有空床位的宿舍并分配
    public boolean assignDorm(int studentId, int dormId) {
        Connection conn = null;
        PreparedStatement ps = null;
        ResultSet rs = null;
        try {
            conn = DBUtil.getConnection();
            // 先查询宿舍是否还有空床位
            String checkSql = "SELECT bed_count, used_bed FROM t_dorm WHERE id=?";
            ps = conn.prepareStatement(checkSql);
            ps.setInt(1, dormId);
            rs = ps.executeQuery();
            if (rs.next()) {
                int bedCount = rs.getInt("bed_count");
                int usedBed = rs.getInt("used_bed");
                if (usedBed < bedCount) {
                    // 有空床位，更新学生宿舍信息
                    String updateStudent = "UPDATE t_student SET dorm_id=? WHERE id=?";
                    ps = conn.prepareStatement(updateStudent);
                    ps.setInt(1, dormId);
                    ps.setInt(2, studentId);
                    ps.executeUpdate();
                    // 更新宿舍已用床位数
                    String updateDorm = "UPDATE t_dorm SET used_bed=used_bed+1 WHERE id=?";
                    ps = conn.prepareStatement(updateDorm);
                    ps.setInt(1, dormId);
                    ps.executeUpdate();
                    return true;
                }
            }
        } catch (SQLException e) {
            e.printStackTrace();
        } finally {
            DBUtil.close(conn, ps, rs);
        }
        return false;
    }
}

界面展示

系统主界面采用Java Swing的BorderLayout布局，顶部为菜单栏和工具栏，左侧为功能导航树，右侧为具体操作面板。整体风格简洁清晰，符合Windows桌面应用的操作习惯。

主要界面包括：

  • 登录界面：管理员身份验证登录
  • 主界面：功能导航 + 信息展示
  • 学生管理界面：学生信息的表格展示与增删改查
  • 宿舍管理界面：宿舍信息管理与分配操作
  • 报修管理界面：报修申请与状态跟踪
  • 访客登记界面：访客信息录入与查询

系统采用MVC架构，View层使用Swing组件，Model层为JavaBean实体类，Controller层通过DAO模式操作数据库，实现了界面与业务逻辑的分离，便于后期维护和扩展。

通过本项目，可以深入理解Java Swing桌面应用开发、JDBC数据库连接与操作、MySQL数据库设计等核心技术，是一个非常适合Java初学者的实战项目。
