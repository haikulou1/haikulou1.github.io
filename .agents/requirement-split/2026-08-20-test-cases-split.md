## 需求理解
- **预期结果与目标用户：** 为教学演示目的，在 Java 项目中添加冒泡排序和最短路径算法的代码示例，要求代码简洁、注释完整，附带单元测试。
- **成功衡量方式：** 每个算法独立可运行（main 方法输出正确结果），单元测试通过，代码注释清晰完整。
- **范围内：**
  - 冒泡排序算法实现（含 main 方法演示 + 单元测试）
  - 最短路径算法实现（含 main 方法演示 + 单元测试）
- **范围外：**
  - HelloWorld 模块（已存在，跳过）
  - 图形化界面 / Web 交互
  - 性能优化或大规模数据测试
  - 算法对比分析或基准测试
- **已确认决策：**
  - 用途为教学示例，非生产代码
  - HelloWorld 已存在，无需重新实现
- **假设与待澄清问题：** 无阻塞性问题。假设最短路径算法使用 Dijkstra 算法（最经典的教学选择），若有偏好在实施时可调整。

## 强制拆分条件分析
尽管总分属于"简单"分类，但以下强制拆分条件被触发：
- **条件 2：需求包含多个可以分别上线、拒绝或排序的用户结果。** 冒泡排序和最短路径算法是两个独立的教学示例，彼此无依赖关系，可独立交付和验收。
- **条件 5：验收标准彼此独立，或一个失败会阻塞无关的价值。** 冒泡排序的测试失败不影响最短路径算法的实现和验收。

因此，建议拆分为 2 个子需求。
